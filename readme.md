## Replit clone

End to end replit clone built with React, Node.js, and Socket.io. This project allows users to create and collaborate on code in real-time, similar to the functionality of Replit. The application features a user-friendly interface for coding, as well as real-time collaboration capabilities that enable multiple users to work on the same codebase simultaneously. The backend is powered by Node.js and Socket.io, which handle the real-time communication between clients and the server. This project serves as a great example of how to build a collaborative coding platform using modern web technologies.

We Also use kubernetes and docker for deployment and scaling of the application. The application is designed to be scalable and can handle a large number of users simultaneously. The use of Kubernetes allows for easy management of the application's resources and ensures high availability. Docker is used to containerize the application, making it easier to deploy and manage across different environments. Overall, this project demonstrates how to build a robust and scalable collaborative coding platform using modern web technologies and containerization tools.
